# TVGuard · 电视时间管家

通过无线 ADB 控制家里的 Android 电视（雷鸟/TCL 系等），实现**按应用限制每日使用时长 + 按时间段限制观看**，家长用手机浏览器管理，电视端无需安装任何东西。

## 功能

- **按应用限额**：如「云视听极光 每天 60 分钟」，超时自动关闭应用回到桌面
- **按时段控制**：如「周一至周五 18:30–20:00 才能看，周末 9:00–21:00」，时段外打开即被关闭；支持跨午夜时段
- **精确计时**：只统计「亮屏 + 应用在前台」的时间，待机、桌面、大人看的其他应用都不扣时长
- **家长面板**（手机浏览器打开）：今日用量进度条、一键加时（+15/+30 分）、暂停控制（大人自己要看时用）、添加/编辑应用规则
- **免配置学包名**：电视上打开某个 App，面板里点一下「填入当前播放的」即可自动识别包名
- **事件日志**：每次拦截、加时、断连都有记录

## 架构

```
Android TV (开ADB调试)  ◄──无线 adb connect──►  TVGuard 服务(NAS/树莓派/电脑)
                                                    ▲
                                            手机浏览器访问面板
```

## 快速开始

### 1. 电视上开启 ADB（雷鸟）

1. 进入 **设置 → 系统 → 系统信息**（部分版本：设置 → 关于本机 → 本机信息）
2. 停留在该页面，用遥控器**依次按 上、下、左、右**，弹出隐藏的 ADB 开关，设为开启
3. 记下电视 IP：设置 → 关于 → 网络状态
4. 首次 `adb connect` 时电视会弹 RSA 授权框，用遥控器选**允许**

> 2024 款 Android 13 新机型该路径可能已失效，若按不出 ADB 开关需另行查方案。

### 2. 部署 TVGuard

**方式 A：直接跑 Python（电脑/树莓派/NAS 均可）**

```bash
# 需先安装 adb（Android platform-tools）并加入 PATH
pip install -r requirements.txt
cp config.example.yaml config.yaml
# 编辑 config.yaml，填入电视 IP

python run.py --preflight   # 先预检：连接、查型号、验证前台识别
python run.py               # 通过后正式启动
```

**方式 B：Docker（NAS 推荐）**

```bash
cp config.example.yaml config.yaml   # 编辑填入电视 IP
docker compose up -d --build
```

> Docker 镜像已内置 adb，无需另外安装。不支持 host 网络的环境见 docker-compose.yml 注释。

### 3. 配置管控规则

浏览器打开 `http://<服务IP>:8787`：

1. 在电视上打开小孩最常用的 App（如云视听极光）
2. 面板点「＋ 添加应用」→「填入当前播放的」，自动填入包名
3. 填显示名称、每日时长、允许时段，保存即生效

常用应用包名参考：云视听极光 `com.ktcp.video`；其他应用用上面的方式识别，或点「查看电视已装应用」从列表里找。

## 使用说明

- **加时**：应用卡片上的 +15分 / +30分，当天有效
- **暂停控制**：面板右上角，15 分钟/1 小时，大人自己要看电视时用
- **每日重置**：默认 0 点重置额度，可在 config.yaml 的 `reset_time` 调整
- **建议设置面板密码**（config.yaml 的 `server.password`），防止家里小孩在局域网自己打开面板加时

## 已知限制

- 拦截方式为 `am force-stop` + 回桌面，从杀掉到下次轮询之间有几秒空隙，超时后应用会被反复关闭，正常情况下无法继续观看
- 投屏内容不经过电视上的应用，本方案管不住投屏
- 电视重启后若 ADB 开关被复位，需重新按「上下左右」开启（面板会显示电视未连接并留事件记录）

## 故障排查

| 现象 | 处理 |
|---|---|
| 面板显示「电视未连接」 | 电视上 ADB 是否被关了；电视和服务端是否同网段；跑 `python run.py --preflight` |
| 添加应用时识别不到前台应用 | 确认电视亮屏且停在该应用内（不是桌面），再点「填入当前播放的」 |
| 电视重启后失联 | 雷鸟部分固件重启后 ADB 开关会复位，重新按上下左右开启 |
| 拦截无效 | 跑 `python run.py --preflight` 确认能识别前台包名；个别应用进程名与包名不同，把识别到的包名发出来排查 |

## 目录结构

```
tvguard/
├── run.py                 # 入口：服务 / --preflight / --list-apps
├── config.yaml            # 静态配置（电视IP、端口、密码）
├── tvguard/
│   ├── adb.py             # ADB 封装（前台识别、force-stop、亮屏检测）
│   ├── monitor.py         # 守护线程：计时 + 拦截
│   ├── store.py           # 规则与用量持久化（data/*.json）
│   ├── web.py             # 面板 API
│   └── templates/index.html
└── data/                  # 运行数据（规则、用量、日志）
```
